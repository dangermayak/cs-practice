рабочая папка (working directory) — где лежат файлы, с которыми ты работаешь;
индекс (staging area) — область, куда ты добавляешь изменения перед коммитом;
коммит — сохранённая версия изменений с сообщением

Git — это локальная система контроля версий: она хранит историю изменений на твоём компьютере.
GitHub — это хостинг для репозиториев: он позволяет хранить код в облаке, делиться им и работать в команде

git status — показывает текущее состояние: какие файлы изменены, какие добавлены в индекс, какая ветка активна.
git diff — сравнивает рабочую папку с индексом (изменения, которые ещё не подготовлены к коммиту).
git diff --staged — сравнивает индекс с последним коммитом (изменения, готовые к коммиту).

Ветка — это указатель на определённую точку в истории коммитов.
При новом коммите ветка автоматически сдвигается вперёд на этот коммит.
Слияние (merge) объединяет изменения из одной ветки в другую, сохраняя историю обеих веток.
