рабочая папка (working directory) — где лежат файлы, с которыми ты работаешь;
индекс (staging area) — область, куда ты добавляешь изменения перед коммитом;
коммит — сохранённая версия изменений с сообщением
Git — это локальная система контроля версий: она хранит историю изменений на твоём компьютере.
GitHub — это хостинг для репозиториев: он позволяет хранить код в облаке, делиться им и работать в команде
