# Заметки по Git

## Сравнение команд

- `git log` показывает историю коммитов: их сообщения и порядок.
- `git diff` сравнивает две версии файлов. В моём случае видна замена сложения на умножение.
- `git show` показывает сведения и изменения одного коммита. Предыдущий коммит содержит этап с вычитанием.

## Поиск и строки файла

- `git log -S"def"` ищет коммиты, в которых менялось количество текста `def` в файле. Результат пустой, потому что в `calc.py` такого текста нет.
- `git blame` показывает, в каком коммите последний раз менялась каждая строка. Первые две строки относятся к коммиту со сложением, третья — к коммиту с умножением.
