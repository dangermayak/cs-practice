# Заметки по Git

## Сравнение команд

- `git log` показывает историю коммитов: их сообщения и порядок.
- `git diff` сравнивает две версии файлов. В моём случае видна замена сложения на умножение.
- `git show` показывает сведения и изменения одного коммита. Предыдущий коммит содержит этап с вычитанием.

- `git restore lab03/calc.py` берёт файл из индекса. В этом упражнении индекс совпадал с последним коммитом, поэтому вернулась сохранённая версия с умножением.
- `git restore --source=HEAD~2 lab03/calc.py` подставляет в рабочий файл версию из более старого коммита, но не передвигает ветку и не создаёт коммит.
- Перед восстановлением полезно посмотреть `git status` и `git diff`: незакоммиченные изменения рабочего файла могут быть потеряны. в каком коммите последний раз менялась каждая строка. Первые две строки относятся к коммиту со сложением, третья — к коммиту с умножением.
- ## Отмена коммита

- `git revert` создаёт новый коммит, который отменяет изменения выбранного коммита. Исходная запись остаётся в истории.
- `git reset --hard` передвигает ветку к другому коммиту и приводит рабочие файлы к его состоянию. Незакоммиченные изменения могут быть потеряны; опубликованную историю так переписывать опасно.
- Для отмены уже опубликованного изменения безопаснее использовать `revert`, потому что он сохраняет общую историю и добавляет в неё отмену.
